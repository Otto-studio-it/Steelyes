# ============================================================
# IMPORTANT NOTES
# ============================================================

# 1. These are PUBLIC environment variables (NEXT_PUBLIC_*)
#    - They are exposed in the browser bundle
#    - Safe to use GitHub Actions Variables (not Secrets)
#    - Next.js inlines them at build time

# 2. DO NOT add runtime secrets here:
#    ❌ NEVER add: SUPABASE_SERVICE_ROLE_KEY
#    ❌ NEVER add: RESEND_API_KEY
#    ❌ NEVER add: Any other sensitive keys
#    → These stay in Coolify environment variables ONLY

# 3. How to set in GitHub:
#    a. Go to repo Settings → Secrets and variables → Actions → Variables tab
#    b. Click "New repository variable"
#    c. Name: (copy from left side above, e.g., NEXT_PUBLIC_SUPABASE_URL)
#    d. Value: (paste your actual value)
#    e. Click "Add variable"
#    f. Repeat for each variable

# 4. No secrets needed for GHCR:
#    - Workflow uses GITHUB_TOKEN (auto-provided)
#    - No manual token setup required

# 5. After setting these variables:
#    - Merge PR #35
#    - Wait for GitHub Actions build to complete
#    - Follow cutover checklist: docs/phase-e-cutover-checklist.md

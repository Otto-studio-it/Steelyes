# Topology — photo-guided CAD base

Generated from `linea guida` + folder photos (2026-07-31).

## double_swing

- **Red:** two leaves (L/R), often arched “swan neck” top on decorative installs; composite vertical boards + scroll bands on the annotated photo.
- **Cyan:** brick/stone pillars.
- **CAD base:** two rectangular leaves, mid rail, vertical pickets (Victorian) or horizontal boards (composite), meeting latch, hinges, optional arch, manual handle if not motorised.
- **Note:** decorative scrollwork is not fully drawn yet — structure first.

## single_swing

- **Linea guida in folder:** REJECTED for topology — annotated photo is a wide picket **sliding-like** panel (mis-tag).
- **Photo lock:** `support-install.jpg` / `photo-A.jpg` = true **single hinged leaf**, hinges left, latch right, often arched ornamental.
- **CAD base:** one rectangular Victorian leaf + mid rail + pickets; arch optional; brick posts. See `ARCHITECT_GAP_LOCK.md`.

## telescopic_sliding

- **LOCKED = 3 overlapping panels** (CA-11 + linea guida + industrial photos).
- 2-leaf Combiarialdo / `L = C/2 + 300` = **VARIANT**, not FROM default.
- **CAD base:** 3 staggered overlapping segments + N parallel tracks + plan cue + motor-side marker.

## tracked_sliding

- **Red (linea guida):** full leaf spanning the driveway opening (often 3 composite bays).
- **Cyan:** end pillars / posts.
- **CAD base:** leaf = **100% clear opening between posts**; **ground track** under opening; runback/motor cue **outside** beyond parking post — never an empty gap inside the posts.
- Differentiator vs cantilever: track in the opening; no triangular counterbalance tail.

## cantilever_sliding

- **Red (linea guida):** leaf body (often 3 composite bays) spanning the driveway opening; **triangular counterbalance AFTER the leaf** on the parking/motor side.
- **CAD base:** leaf = **100% clear opening between posts**; triangle + carriage **beyond** the right/guide post; **no ground track** across the opening.
- Do **not** squeeze the triangle into the opening — that misreads as tracked and under-sizes the leaf.

## bifolding_double_swing

- **Red:** two leaves, each split mid-leaf (4 panels total), mid rail, pickets, finials on photo.
- **Cyan:** masonry pillars; actuators visible on photo (not drawn as product UI yet).
- **CAD base:** double swing + dashed fold stile per leaf (50/50).

## single_bifolding

- **Photo lock (`foto /single bifloding gates` linea guida):** **one leaf**, two red panels 50/50; cyan = heavy hinge post.
- **CAD base:** leaf fills clear opening; mid fold stile + fold hinges; stack outside hinge post; receiver on free post; leading bumper cue.
- Wiki double-leaf screenshots are **not** this topology (use for hardware mood only).

## radius_sliding

- **Red:** articulated multi-panel **train** (hinged end-to-end) spanning the opening.
- **Cyan:** posts, **curved ground track** (~90° park beside wall), corner guide + motor.
- **CAD base:** 4–6 elevation panels + hinge stiles + curved track + plan park cue.
- **Not telescopic** — `Screenshot … 20.13.46` in the foto folder is a misfile.
- When `arched_top`: **every** panel crest is curved.

# Single bifolding notes

- Linea guida lock: **one leaf, two equal panels**, heavy hinge post, leading bumper.
- CA-10: stack on hinge side; preview hinge-left; real L/R at quote.
- Do not confuse with `bifolding_double_swing` (4 panels) or plain `single_swing` (no fold).
- Mesh Wiki render = optional product language, not a sixth silhouette family yet.

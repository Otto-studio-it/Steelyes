# Steelyes Photo Shortlist

Source reviewed: `/Volumes/SSDRubb/foto steelyes`

This shortlist is based on the full client folder, not only the existing site assets.
The goal is to shift the vetrina away from a gate-only impression and show:

- gates
- railings and balustrades
- balconies and terrace systems
- staircases and structural steel
- fabrication / workshop proof
- detail / finish quality

## Executive read

- The folder is strong enough to build the full vetrina without asking for more photos.
- The biggest visual gap is not quantity, it is balance.
- Best coverage for the website comes from a mix of:
  - wide gate hero shots
  - railing and balcony installations
  - staircase / steel structure shots
  - close detail proof
  - a small number of branding / workshop images

## What to avoid as main visuals

These are not bad files, but they should not drive the first impression.

- phone screenshots
- marketing card graphics
- shirt mockups
- repeated near-identical gate angles
- generic scaffold-only construction shots unless they prove a special project

## Page-by-page recommendation

### Home

Use a mix that immediately says the business is wider than gates:

- one wide gate hero
- one fabrication / structure shot
- one terrace or balcony shot
- one detail / finish image

Best set:

- `1000048883.JPG`
- `1000052013.JPG`

- `1000048813.JPG`

### Gallery

Build the gallery in blocks, not as a random mix:

- gates
- railings
- balconies
- staircases
- fabrication / detail

This lets the visitor see breadth fast.

## Conclusion

The folder already contains enough material to reframe Steelyes as a broader steel fabrication company, not only a gates business.
The main move now is editorial:

- pick fewer gate-only images
- increase railings, balconies, staircases and fabrication
- use details as proof of quality
- keep branding images secondary

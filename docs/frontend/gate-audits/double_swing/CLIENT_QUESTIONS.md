# Double swing client questions

Use these questions to close the remaining `double_swing` gaps with the client.

Keep answers short and concrete.

---

## 1. Size semantics

1. Does `widthMm` mean clear opening only, or clear opening plus posts/pillars?
2. Does `heightMm` mean the rectangular gate body only, or body plus arch?
3. Are the published `1800/1900 mm` and `900/1000 mm` bands minimum-to-maximum ranges, or just example presets?
4. Do the reference photos represent the same catalog size, or are they larger site-specific installs?

## 2. Structure

5. How many horizontal rails should the Victorian double swing have in production?
6. What is the exact tube section for the outer frame?
7. What is the exact picket spacing or center-to-center pitch?
8. What is the exact ground clearance target?
9. Should the center meeting detail be a decorative latch plate, a simple latch, or both?
10. Is the drop bolt always present, or only on some installs?

## 3. Decoration mapping

11. Which visual element is the real product match for the top and bottom circular bands?
12. Which visual element is the real product match for basket twist details?
13. Which visual element is the real product match for the spear row at the middle?
14. Should `bushes` and `spirals` stay as the current approximations, or do they need new product names?
15. Is `top_railheads` supposed to mean a finial on every picket, or a smaller counted set?

## 4. Style and option rules

16. Is `Traditional Victorian Style` the only style that should show the full Victorian decoration set?
17. Should `Composite Boards` reuse the same pricing logic but a different infill drawing?
18. Is `arched_top` always valid for `double_swing`, or only on some widths?
19. Are `dog_bars` and `dog_bar_railheads` separate options in production, or only visual labels?

## 5. Preview reference

20. Which single photo should be treated as the baseline reference for the final 2D preview?
21. Should the final preview match photo 02, 03, or 04 most closely?
22. Do you want the preview to show brick pillars by default, or only the gate assembly?

---

## 6. What we need back

For each answer, ask for:

- exact value
- yes/no
- one preferred reference photo
- one confirmed visual mapping

If the answer is uncertain, mark it as provisional instead of guessing.

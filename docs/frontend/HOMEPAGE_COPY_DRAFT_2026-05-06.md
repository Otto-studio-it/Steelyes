# Steelyes - Homepage Copy Draft

This document defines the proposed homepage copy before implementation. The goal is to replace placeholder text with credible, SEO-aware copy while keeping the approved visual direction and avoiding unconfirmed claims.

The homepage should do four jobs:

- explain immediately that Steelyes builds bespoke steel gates;
- push visitors toward a quote request without hiding the configurator;
- give Google clear product/service language;
- use the client photo set to make the page feel real, not generic.

---

## Positioning

### Core promise

Bespoke steel gates, built to define your property.

### Why this promise

This is stronger than the current "Your gate, built by hand" because it keeps the craft message but adds commercial clarity. It tells the visitor what is being sold, uses a searchable phrase ("bespoke steel gates"), and frames the product as a property upgrade rather than a decorative object.

The homepage should repeatedly support this promise with:

- made-to-measure design;
- driveway, pedestrian, sliding, cantilever, and automated gates;
- survey-led specification;
- steel fabrication;
- supply and installation;
- real installed-project photography.

## CTA Strategy

Use both CTAs.

Primary CTA:

```txt
Request a Quote
```

Target route:

```txt
/contact
```

Reason:

The quote request is the safest commercial conversion path because final pricing, finishes, railheads, and some catalogue details are still waiting on client confirmation.

Secondary CTA:

```txt
Configure Your Gate
```

Target route:

```txt
/configurator
```

Reason:

The configurator is a strong differentiator and should stay visible. It should be positioned as an exploration tool, not as a final checkout or fixed-price promise.

Avoid making "View our work" the main secondary CTA in the hero. Gallery remains important, but the two strongest business actions are quote and configure.

### Image direction

Use the strongest completed gate photo available. The gate must be visible in context: driveway, entrance, pillars, wall line, or property frontage. Avoid workshop-only shots in the hero.

Preferred image characteristics:

- finished gate installed on site;
- enough surrounding context to understand scale;
- no visible private data, number plates, or faces;
- sharp image with strong contrast;
- landscape crop that still works on mobile.

### Rationale

This section must answer "what do they do?" in under three seconds. The current hero is visually strong but too generic. The new copy gives Google and users the exact category while preserving the premium, craft-led tone.

## Section 4 - The Process

This is the section the current homepage already handles best structurally. Keep the four-step layout and replace only the placeholder copy.

### Heading

```txt
The process
```

Optional intro:

```txt
From first photos to final handover, every gate starts with the opening it needs to serve.
```

### Step 01 - Consultation

```txt
Tell us about the entrance, access, style, automation needs and any photos, sketches or measurements you already have.
```

### Step 02 - Specification

```txt
We turn the brief into dimensions, steel sections, finish direction, automation options and survey requirements.
```

### Step 03 - Fabrication

```txt
Your gate is built to the agreed specification, with steelwork prepared for finishing, hardware and installation.
```

### Step 04 - Installation

```txt
We coordinate delivery, fitting, alignment, handover and final adjustments so the gate works cleanly on site.
```

### Rationale

The process section reduces buyer uncertainty. Visitors buying a bespoke gate need to know that the company can move from vague idea to measured specification. This also supports the quote CTA because it explains why a survey-led quote is normal.

## Image Allocation Plan

The selected client photos should be sorted into these buckets before implementation:

| Homepage area | Photo type needed | Priority |
|---|---|---|
| Hero | Best installed gate in real entrance context | Critical |
| Modern card | Contemporary gate, clean lines | High |
| Classic card | Traditional or decorative steel gate | High |
| Privacy card | Closed or semi-closed privacy gate | High |
| Process | Survey, fabrication, installation or detail shot | Medium |
| Configurator | No real photo required unless using background texture/detail | Low |
| Proof/gallery | 2-4 real project/detail photos | Critical |
| Final CTA | Optional strong detail crop or completed gate | Medium |

Photo rejection rules:

- no visible number plates unless blurred or cropped;
- no visible faces unless permission is confirmed;
- no private addresses, house numbers or identifying signs;
- no blurry or low-resolution images for hero/cards;
- no dark workshop-only image as primary homepage proof;
- no image where the actual gate is too small to inspect.

## Recommended Homepage Order

1. Hero: promise, primary quote CTA, configurator CTA.
2. Trust/capability strip: safe capability statements.
3. Gate styles: Modern, Classic, Privacy.
4. Process: consultation, specification, fabrication, installation.
5. Configurator teaser: digital differentiator.
6. Proof/gallery/workshop: real photos, no fake testimonial.
7. Final CTA: request quote.

This order gives visitors the right sequence: understand, trust, explore, learn process, interact, verify, act.

## Implementation Notes For Workers

- Keep the approved visual style; this is a copy and image replacement pass, not a redesign.
- Use UK English spelling: "galvanised", "specialist", "specification".
- Keep both hero CTAs.
- Do not publish exact statistics, warranty claims, fixed prices or named testimonials unless the client confirms them.
- Keep internal links to `/contact`, `/configurator`, `/gates`, `/gallery` and `/installation`.
- Use descriptive image alt text with natural keywords, for example:

```txt
Bespoke black steel driveway gate installed at a residential entrance
```

- Do not overuse the same phrase in every alt tag. Write alt text for the actual image.
- Treat the homepage as the source of tone for the rest of the marketing site.
